One stylesheet · three renderers

The same felt card — a flex column whose body uses flex-grow: 1 to push the footer down — rendered as a native React component, a web component in shadow DOM, and a web component in light DOM. All three are styled by a single shared stylesheet. Use the toggles to change how the CSS is authored (selector strategy) and how it's delivered (a <link> + inline <style>, or adopted stylesheets).
